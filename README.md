# Assembly + Binary Bomb

Домашняя работа по x86-64 assembly для Linux. Исходники используют AT&T-синтаксис и System V ABI.

## Задачи

- `hello.s` — печатает `Hello, world!` через `puts`.
- `sum.s` — складывает `20` и `22` инструкцией `addq`, затем печатает `42`.
- `fib.s` — циклом вычисляет `F(10)` и печатает `55`.
- Binary Bomb — разобрана на учебном сервере; ответы и отчёт хранятся локально и сдаются преподавателю приватно.

## Сборка и запуск

Требуются Linux x86-64, `clang`, GNU Make и libc.

```sh
make
make run
```

Эквивалентная ручная сборка:

```sh
clang -no-pie hello.s -o hello
clang -no-pie sum.s -o sum
clang -no-pie fib.s -o fib
```

`-no-pie` используется только как учебное упрощение для стабильных адресов в дизассемблере и отладчике. Это не production-рекомендация.

## Регистры

### Сложение

- `%rax` хранит первое слагаемое, затем сумму.
- `%rcx` хранит второе слагаемое.
- `%rdi` и `%rsi` передают формат и результат в `printf`.
- `%eax` обнуляется перед variadic-вызовом `printf`, сообщая, что векторные регистры для аргументов не используются.

### Fibonacci

- `%rax` хранит текущее значение `F(i)`.
- `%rdx` хранит следующее значение `F(i + 1)`.
- `%r8` временно хранит сумму двух значений.
- `%rcx` хранит число оставшихся итераций.

Каждый цикл переводит пару `(F(i), F(i + 1))` в `(F(i + 1), F(i + 2))`. Поэтому результат вычисляется, а не загружается готовой константой.
